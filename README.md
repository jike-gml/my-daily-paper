# MY DAILY PAPER

自分専用の毎日新聞アプリのプロトタイプです。

## 現在の機能

- スマートフォン向けレスポンシブ表示
- 3ジャンル選択
- 各ジャンル最大2項目の絞り込み入力
- 端末内への設定保存（localStorage）
- ジャンル別表示
- A4縦の新聞レイアウト
- ブラウザ標準印刷
- PDF保存

## 現在の状態

このリポジトリはUI・紙面構成確認用のプロトタイプです。
表示される記事・画像はダミーデータです。

実装版では、選択した3ジャンルについて公式一次情報を収集し、
タイトル、公開日時、発表元、公式URL、画像情報などを扱う予定です。

## 方針

- ニュースサイトの転載ではなく公式一次情報を優先
- AIを前提としないルールベース処理
- 日本語情報を基本とし、外国語ソースは必要な場合のみ翻訳処理
- スマートフォンではニュースアプリ型UI
- 印刷時はA4新聞型レイアウト
- 保存はスマートフォン端末内を基本とする
- 写真は利用条件を確認できるものだけ使用

## 使い方

`index.html` をブラウザで開いてください。

### ジャンル設定

「ジャンル設定」から3ジャンルを指定できます。
各ジャンルには任意の絞り込み項目を最大2つ設定できます。

### 端末保存

「端末に保存」を押すと、プロトタイプではブラウザの `localStorage` に設定情報を保存します。

### 印刷

「A4印刷」を押すとブラウザの印刷画面を開きます。

推奨:
- 用紙: A4
- 向き: 縦
- 出力: プリンター または PDF
